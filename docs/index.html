BuddyClip
GitHub v0.1.3 APK

Encrypted clipboard sync over Tailscale.

Shared Rust core for Linux and Android. Tailnet-only, end-to-end encrypted, RAM-only, no cloud.

Install Linux + Android Source on GitHub
Highly experimental (v0.1.3). Personal tool—not security-audited, protocol and CLI may break. Tested on Wayland + Android 15–16 (ARM64).

How it works

wl-paste Tailnet E2EE 0-tap write

Linux PC

Watches Ctrl+C for text and images, skipping password-manager clips.

Tailnet + E2EE

Tailscale IPs only. Ephemeral X25519 + 256-bit PSK auth over WireGuard.

Android

Rust JNI foreground service writes straight to your clipboard in 0 taps.

Install

Linux PC

curl -fsSL https://raw.githubusercontent.com/OxFrancesco/BuddyClip/main/install.sh | bash

Run buddyclip init, then buddyclip install-service.

Android

Download v0.1.3 APK (ARM64)

Install APK, tap Scan QR, scan your terminal.

RAM-only (25 items / 64 MiB) · Password managers skipped · Tagged Tailscale phones need TCP 9455
